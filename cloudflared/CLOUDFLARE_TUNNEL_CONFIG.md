# Cloudflare Tunnel Configuration for arback.jsdeveloper.cloud

Complete configuration guide for setting up Cloudflare tunnel for your API backend.

## Files Needed

1. `cloudflared/config.yml` - Tunnel configuration
2. `cloudflared/credentials.json` - Tunnel credentials (generated by setup script)

## Configuration File

### `cloudflared/config.yml`

```yaml
# Cloudflare Tunnel Configuration for AR-13 API Backend
# Domain: arback.jsdeveloper.cloud

tunnel: YOUR_TUNNEL_ID_HERE
credentials-file: /etc/cloudflared/credentials.json

# Ingress rules - define how traffic is routed
ingress:
  # API endpoints - route all traffic from domain to Docker backend
  - hostname: arback.jsdeveloper.cloud
    service: http://server:3000
  
  # Catch-all rule (must be last)
  - service: http_status:404
```

**Important:** Replace `YOUR_TUNNEL_ID_HERE` with your actual tunnel ID from `credentials.json`.

## Setup Steps

### Step 1: Create Tunnel

Run the setup script:

```bash
cd cloudflared
chmod +x setup-api-tunnel.sh
./setup-api-tunnel.sh ar13-api-tunnel arback.jsdeveloper.cloud
```

This will:
- Create tunnel in Cloudflare
- Generate `credentials.json`
- Create DNS route
- Generate `config.yml` with your domain

### Step 2: Verify Config

Check `cloudflared/config.yml`:

```bash
cat cloudflared/config.yml
```

Should show:
- `tunnel: <your-tunnel-id>`
- `hostname: arback.jsdeveloper.cloud`
- `service: http://server:3000`

### Step 3: Enable in Docker Compose

Uncomment the cloudflared service in `docker-compose.yml`:

```yaml
cloudflared:
  image: cloudflare/cloudflared:latest
  container_name: ar-13-cloudflared
  restart: unless-stopped
  command: tunnel --config /etc/cloudflared/config.yml run
  volumes:
    - ./cloudflared/config.yml:/etc/cloudflared/config.yml:ro
    - ./cloudflared/credentials.json:/etc/cloudflared/credentials.json:ro
  networks:
    - ar-13-network
  depends_on:
    - server
  mem_limit: 128m
  mem_reservation: 50m
```

### Step 4: Start Services

```bash
docker-compose up -d
```

### Step 5: Verify

```bash
# Check tunnel is running
docker logs ar-13-cloudflared

# Test API
curl https://arback.jsdeveloper.cloud/api/health
```

## Alternative: Manual Configuration

If you prefer to configure manually in Cloudflare Dashboard:

### 1. Create Tunnel in Dashboard

1. Go to Cloudflare Dashboard → Zero Trust → Networks → Tunnels
2. Click "Create a tunnel"
3. Choose "Cloudflared"
4. Name: `ar13-api-tunnel`
5. Download `credentials.json`

### 2. Configure Public Hostname

1. Go to your tunnel → Public Hostnames
2. Add hostname:
   - **Subdomain:** `arback`
   - **Domain:** `jsdeveloper.cloud`
   - **Service:** `http://server:3000` (or `http://localhost:3000` if using host network)
   - **Path:** (leave empty)

### 3. Update config.yml

Place `credentials.json` in `cloudflared/` directory and update `config.yml` with your tunnel ID.

## Advanced Configuration

### Multiple Hostnames

```yaml
ingress:
  - hostname: arback.jsdeveloper.cloud
    service: http://server:3000
  - hostname: api-staging.jsdeveloper.cloud
    service: http://server:3000
  - service: http_status:404
```

### Path-based Routing

```yaml
ingress:
  - hostname: arback.jsdeveloper.cloud
    path: /api/*
    service: http://server:3000
  - hostname: arback.jsdeveloper.cloud
    path: /uploads/*
    service: http://server:3000
  - service: http_status:404
```

### Using Host Network (if needed)

If you need to access `localhost:3000` instead of Docker service:

```yaml
# In docker-compose.yml, uncomment:
network_mode: "host"

# In config.yml, change to:
service: http://localhost:3000
```

## Troubleshooting

### Tunnel Not Connecting

```bash
# Check credentials
cat cloudflared/credentials.json

# Check config syntax
docker run --rm \
  -v $(pwd)/cloudflared:/etc/cloudflared \
  cloudflare/cloudflared:latest \
  tunnel --config /etc/cloudflared/config.yml ingress validate

# Check logs
docker logs ar-13-cloudflared
```

### Service Not Accessible

```bash
# Check backend is running
docker-compose ps
curl http://localhost:3000/api/health

# Check network
docker network inspect ar-13-network
```

### DNS Issues

- Verify DNS record in Cloudflare Dashboard
- Should be CNAME pointing to tunnel
- Created automatically by setup script

## Notes

- `credentials.json` is sensitive - never commit to git (already in `.gitignore`)
- Tunnel ID is in both `config.yml` and `credentials.json`
- Service name `server:3000` matches Docker Compose service name
- Catch-all rule (`http_status:404`) must be last in ingress list
